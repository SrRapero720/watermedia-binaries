<h1 style="color: #EB622B;"><strong>📦 WATERMeDIA: BINARIES</strong></h1>

_FFmpeg_ 9 natives for [WATERMeDIA](https://www.curseforge.com/minecraft/mc-mods/watermedia), plus _yt-dlp_ for
YouTube, SoundCloud, Facebook and Instagram. Nothing to compile or install, just plug and play.

- Required on Minecraft clients, optional on dedicated servers
- Use it with the same WATERMeDIA version (3.0 with 3.0)
